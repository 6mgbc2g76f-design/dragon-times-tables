DRAGON TIMES TABLES — INSTALL ON IPAD

1. Unzip this package. Keep the files together.
2. Create a free GitHub account at github.com (if needed).
3. Create a new PUBLIC repository, e.g. dragon-times-tables.
4. Upload ALL the files INSIDE this folder to the repository root (not the ZIP itself).
5. In repository Settings > Pages, choose Deploy from a branch, branch main, folder /(root), then Save.
6. Wait for GitHub Pages to publish the site. Your URL will usually be https://YOUR-USERNAME.github.io/dragon-times-tables/
7. On the iPad, open that URL in Safari, tap Share > Add to Home Screen, enable Open as Web App if offered, and tap Add.
8. Launch it from the dragon icon. Open it online once so it can cache its files for offline use.

Notes:
- The app runs offline after its files have been cached; avoid clearing Safari website data if you want offline access.
- Progress is held in memory for each session, not saved after the app is closed.
- GitHub Pages on a public repository makes the game's code publicly viewable; no personal information is required in the game.
- If you update the files later, allow the app to connect to the internet to receive updates.
